# Regels voor deze workspace

- Je hoeft de gebruiker niet om toestemming te vragen in de chat om unit tests uit te voeren. Voer deze proactief en direct uit als dat nodig is voor verificatie.
- Push NOOIT automatisch naar GitHub (of een remote git repository) tenzij de gebruiker hier expliciet en specifiek om vraagt. De gebruiker wil wijzigingen altijd eerst lokaal testen op fouten of neveneffecten.
