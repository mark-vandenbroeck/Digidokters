PWA & Client-zijde

Gebruikers werken in de PWA. De Service Worker zorgt voor offline-beschikbaarheid van de interface. Invoer van bezoeken en documenten wordt via HTTPS-formulieren naar de server gestuurd.

Flask Backend (Render)

De backend verwerkt alle aanvragen, regelt multi-tenant data-scheiding op basis van de ingelogde organisatie en logt elke wijziging in de database automatisch via SQLAlchemy event-listeners.

Database (Supabase)

Gegevens worden geïsoleerd opgeslagen via Row Level Security (RLS) op PostgreSQL. Documenten worden als binaire data bewaard voor automatische backups.

E-mail (Brevo)

Render stuurt HTTPS POST-verzoeken naar de Brevo API om veilig transactie-mails (zoals verificatiecodes voor wachtwoordherstel) te verzenden naar gebruikers.
